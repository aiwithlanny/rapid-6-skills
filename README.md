# RAPID 6.0 官方 Skill 包（私有）

僅供課程學員下載。請勿公開轉發。

## 安裝方式（Codex／Claude）

1. 下載對應 zip（**不用解壓縮**）
2. 上傳到 AI，說：「請幫我安裝這個 Skill」
